# 模型 A 暂定结果

## 结果状态

本页数字由 `03_model_a_formal_phonological_ridge.ipynb` 的完整模式生成，使用 20 个预先固定的少样本随机种子。当前 108 个拟声拟态词仍使用自动词族候选，因此状态为 `provisional_candidate_families`。完成词族人工确认后必须原样重跑，才能作为论文最终结果。

## 整体 MAE

| 模型 | 0 个支持词 | 16 个支持词 | 32 个支持词 |
|---|---:|---:|---:|
| 平均值基准 | 0.7436 | 0.7421 | 0.7408 |
| 仅音拍数 Ridge | 0.7466 | 0.7450 | 0.7438 |
| 普通词中可学习的音韵特征 | 0.7478 | 0.7461 | 0.7440 |
| 全部 12 个音韵特征 | 0.7478 | 0.7476 | 0.7435 |

全部特征 Ridge 的 95% 词族 bootstrap 区间分别为：

- 0 样本：0.7049–0.7912。
- 16 样本：0.7031–0.7943。
- 32 样本：0.7003–0.7873。

## 当前能说明什么

仅使用这些手工音韵计数时，Ridge 在整体 MAE 上没有稳定超过同条件平均值基准。全部特征 Ridge 相对平均值基准的整体 MAE 差值在 0、16、32 样本条件分别为 +0.0041、+0.0055、+0.0027，成对置换检验均不显著。正值表示 Ridge 误差稍高。

全部特征 Ridge 从 0 样本增加到 32 样本后，整体 MAE 降低约 0.0042，但词族层级成对检验不显著（p = 0.335）。嗅觉维度降低约 0.0112，并通过六维 FDR 校正；不过平均值基准在嗅觉上也出现几乎相同的改善，而且 Ridge 与平均值基准的差距接近零。因此这更可能来自少量目标词改变了训练集平均值，不能据此声称音韵特征学到了稳定的嗅觉规律。

内层交叉验证经常选择极强的正则化，使系数接近零。这与整体结果一致：对不少划分和感官维度，训练数据支持“退回平均值预测”，而不是依靠当前特征做强预测。

## 对后续实验的意义

模型 A 已经完成它作为基准的任务：它给出了简单、透明且严格防止词族泄漏的下限。后续模型 B 应检验日语文本表示是否包含手工计数没有捕捉到的信息；模型 C 再检验文本表示与音韵特征结合后是否有额外增益。三个模型必须复用 `model_a_support_samples.csv` 中的测试折、支持词和随机种子。

现阶段不应通过不断增加手工特征来追逐当前测试结果。先完成词族审查并冻结划分，再按既定方案运行模型 B、C，才能保持会议论文所需的比较可信度。
