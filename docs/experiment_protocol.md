# 实验方案：音韵Ridge基准

## 研究目标

检验从日语普通词学到的音韵—感官映射能否迁移到拟声拟态词，以及加入16或32个拟声拟态词后预测误差是否下降。

## 数据

主要分析使用504个词：396个普通词和108个拟声拟态词。6个待核对词保留在主文件中，但 `use_in_primary_analysis` 标记为0。

## 输入与输出

输入为12个自动计算的音韵特征，包括音拍数、完全重复、促音、撥音、长音、浊阻音、p系列音和五个元音计数。输出为六项平均感官评分。

## 外层测试

108个拟声拟态词按词族候选分为三折。每次保留一折作为测试集，其余两折作为拟声拟态词支持样本池。同一词族不能同时进入训练集和测试集。

当前 `family_candidate_key` 为自动生成，三折状态为暂定。正式论文分析前需要检查词族划分。

## 训练条件

- 0样本：396个普通词。
- 16样本：396个普通词加16个拟声拟态词。
- 32样本：396个普通词加32个拟声拟态词。

同一随机种子下，16个支持词是32个支持词的子集。16和32样本条件使用5个固定随机种子。0样本条件为确定性模型，只运行一次。

## 模型

- 平均值基准：对每个感官维度预测训练集平均值。
- 音韵Ridge：`StandardScaler` 加多输出Ridge回归。
- Ridge正则强度只在训练集内部选择，不使用外层测试集。

## 评价

主要指标为六项感官评分的平均绝对误差（MAE）。同时记录每个感官维度的MAE和六个维度Spearman相关的平均值。MAE越低越好。

## 解释限制

结果反映预测关系，不直接证明音韵特征造成了人类感官联想。0样本表示模型没有使用本数据集中的拟声拟态词评分，并不表示预训练语言模型从未在语料中见过这些词。
