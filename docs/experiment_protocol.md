# 实验方案：模型 A 正式版（音韵 Ridge）

## 研究目标

检验从日语普通词学到的音韵—感官映射能否迁移到拟声拟态词，以及加入16或32个拟声拟态词后预测误差是否下降。

## 数据

主要分析使用504个词：396个普通词和108个拟声拟态词。6个待核对词保留在主文件中，但 `use_in_primary_analysis` 标记为0。

## 输入与输出

输入为 12 个自动计算的音韵特征，包括音拍数、完全重复、促音、撥音、长音、浊阻音、p 系列音和五个元音计数。输出为六项平均感官评分。

为确认模型的增益来自哪里，比较四个层级：

1. 训练集感官平均值。
2. 仅音拍数的 Ridge。
3. 仅使用普通词中存在变化的音韵特征的 Ridge。
4. 使用全部 12 个特征的 Ridge，作为主要模型 A。

第三个模型专门检查域偏移：促音和撥音在当前普通词训练集里没有变化，却出现在部分拟声拟态词中，因此零样本条件下无法从普通词学习它们的作用。

## 外层测试

108 个拟声拟态词按词族分为三折。每次保留一折作为测试集，其余两折作为拟声拟态词支持样本池。同一词族不能同时进入训练集和测试集。

当前 `family_candidate_key` 为自动生成，三折状态为暂定。使用 `data/review/ideophone_family_review.xlsx` 完成人工检查。主表中的 `family_id`、`family_review_status` 和最终折号全部确认后，才可把结果标为 final。

## 训练条件

- 0样本：396个普通词。
- 16样本：396个普通词加16个拟声拟态词。
- 32样本：396个普通词加32个拟声拟态词。

同一随机种子下，16 个支持词是 32 个支持词的子集。每个支持词来自不同词族，同一词族不会在一次抽样中贡献两个词。16 和 32 样本条件使用实验前固定的 20 个随机种子。0 样本条件为确定性模型，每折只运行一次。

## 模型

- 平均值基准：对每个感官维度预测训练集平均值。
- 音韵 Ridge：`StandardScaler` 加 Ridge 回归。
- 六个感官维度分别训练并选择正则强度，不再共用一个 alpha。
- alpha 网格为 `10^-8` 到 `10^8` 的 25 个对数间隔值。两个端点分别近似无正则化和只预测截距，用于覆盖数据支持很弱或很强的收缩情况。
- 内层三折使用 `GroupKFold`，词族作为 group。外层测试词不参与调参。

## 评价

主要指标为六项感官评分的平均绝对误差（MAE），MAE 越低越好。同时报告每个感官维度的 MAE 和 Spearman 相关。

置信区间和显著性检验使用词族作为独立单位：

- 先在每个词上平均不同随机种子的绝对误差，再在词族内平均。
- 使用词族 bootstrap 计算 95% 置信区间。
- 使用成对符号翻转置换检验比较 Ridge 与同条件平均值基准。
- 对六个感官维度的 p 值使用 Benjamini–Hochberg FDR 校正。
- 主要模型另比较 32 样本与 0 样本条件。

正式模型 A 的可复现输出为：

- `results/model_a_predictions.csv`
- `results/model_a_run_metrics.csv`
- `results/model_a_coefficients.csv`
- `results/model_a_support_samples.csv`
- `results/model_a_bootstrap_summary.csv`
- `results/model_a_statistical_tests.csv`
- `results/model_a_feature_shift.csv`

## 解释限制

结果反映预测关系，不直接证明音韵特征造成了人类感官联想。模型 A 的 0 样本表示 Ridge 没有使用本数据集中的拟声拟态词评分。

词族确认前的输出用于检查实验和形成假设，不能作为投稿中的最终数字。后续模型 B、C 必须使用同一外层测试折、同一支持样本清单和同一评价代码，避免比较时改变数据划分。
